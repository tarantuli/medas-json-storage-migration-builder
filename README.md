# medas-json-storage-migration-builder

Part of the [Medas framework](https://github.com/tarantuli/medas-core).

## Description

The `medas-migration-builder` driver for `medas-json-storage`. Implements the `MigrationBuilder` interface for `StorageDirectory` backends, generating PHP migration class code that creates or deletes JSON store files.

When `MigrationFactory` scans an entity annotated with `#[Entity(storage: 'json-data')]`, it calls this builder's `build()` method. If the corresponding `.json` file does not already exist (or `ignoreExistingStructure` is `true`), a `CreateStore` action is emitted into the migration's `migrate()` method body. The action creates the JSON file pre-populated with the store's metadata (primary key name, field names, defaults, and an empty `data` array).

`DeleteStoreBuilder` generates a `DeleteStore` action that removes the `.json` file when the `undo()` method is run.

## Usage

### Package developer context

Register the package — it is pulled in automatically when you use `medas-json-storage` alongside `medas-migration-builder`:

```php
use Medas\JsonStorageMigrationBuilder\JsonStorageMigrationBuilderPackage;

JsonStorageMigrationBuilderPackage::instance();
```

**Generated migration example** for a `Settings` entity backed by JSON storage:

```php
// Generated by: php bin/medas migration-builder:make-migration
class Migration20260522120000 implements Migration
{
    public function migrate(UnitOfWork $unitOfWork): void
    {
        $unitOfWork->addAction(new \Medas\JsonStorage\Actions\CreateStore\CreateStore(
            "json-data",
            "/var/data/settings.json",
            '{
    "keyName": "id",
    "fieldNames": ["id", "key", "value"],
    "defaults": {"id": null, "key": null, "value": null},
    "data": []
}'
        ));
    }

    public function undo(UnitOfWork $unitOfWork): void
    {
        // undo actions generated by DeleteStoreBuilder
    }
}
```

See `medas-migration-builder` for the `make-migration` console command and `medas-storage-manager` for running migrations.

### Backend user context

No configuration is required beyond what `medas-json-storage` already needs. Once both packages are registered, `make-migration` will automatically use this builder for any entity routed to a `StorageDirectory` backend.
